# Подпись драйвера, чтобы он грузился у обычных пользователей (Windows 10/11, Secure Boot включён)

Короткий и честный ответ: **без подписи Microsoft драйвер у обычного пользователя не загрузится.** Самоподписанный сертификат (в т. ч. из CI) работает только в disposable VM с выключенным Secure Boot. «Один батник для всех» возможен лишь после того, как драйвер подпишет Microsoft.

## Единственный путь к «работает у всех»: attestation signing

1. **Партнёрский аккаунт.** Microsoft Partner Center → Hardware program. Нужна организация (или ИП) и разовая регистрация.
2. **EV code-signing сертификат.** Покупается у CA (DigiCert, Sectigo и т. п.), выдаётся на аппаратном токене/в облачном HSM. Им подписывается заявка в Partner Center. Стоит денег и требует проверки личности/организации.
3. **Заявка на attestation.** Собрать `.cab` с драйвером, подписать EV-сертификатом, отправить в Hardware dashboard. Microsoft возвращает драйвер, подписанный своей цепочкой. Такой драйвер грузится на Windows 10/11 с Secure Boot без test-signing и без watermark.
4. **Автоматизация.** Всё это есть в Hardware API (Azure AD app → Partner Center). Тогда CI-воркфлоу `driver-sign.yml` в режиме `attest` сам отправит сборку и заберёт подписанный драйвер.

Чтобы CI делал это сам, задайте секреты репозитория:
`PARTNER_TENANT_ID`, `PARTNER_CLIENT_ID`, `PARTNER_CLIENT_SECRET`, `PARTNER_SELLER_ID`, и загрузите EV-сертификат в Hardware dashboard. Пока секретов нет, режим `attest` честно падает с инструкцией и ничего не подделывает.

## Что работает уже сейчас (без денег и аккаунта)

- CI-воркфлоу `driver-sign.yml` режим `test`: собирает и подписывает драйвер самоподписанным сертификатом, выкладывает `.sys` + `.cer` + батник активации.
- `packaging/driver/Активировать-драйвер.cmd` (+ `Activate-DisposableVM.ps1`): в **одноразовой VM** импортирует сертификат, включает test-signing (одна перезагрузка; Secure Boot должен быть выключен), создаёт и запускает службу, прогоняет SYS-путь. На рабочем ПК и при включённом Secure Boot скрипт сам отказывается работать.

## Почему батник не может «просто включить» драйвер на обычном ПК

Загрузку неподписанных/самоподписанных драйверов блокирует само ядро Windows (Code Integrity) ещё до запуска драйвера. Обойти это можно только выключив Secure Boot и включив test-signing — то есть ослабив защиту машины, что запрещено нашими же правилами. Поэтому «активация одним кликом для всех» = attestation-подпись, другого пути нет.
