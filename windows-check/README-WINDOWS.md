# ElasticMem 0.21.0 — начать здесь

Для Edge: запустите ElasticMem на том же ПК, откройте2–4вкладки → **Лаборатория → Только Microsoft Edge → Проверить Chrome / Edge (коротко)**. Агент остановится;15с счётчиков + Г1/Г4/ZIP, без trim браузера/GPU. На другой ПК приложение не подключается. По умолчанию авто предпочитает пару Edge, затем Chrome, а не Steam.

Контроль без браузера: **Лаборатория → Контроль доступа (без браузера)**. Остановите агент и другие тесты. Нужен запас512МиБ RAM; браузер/галочка trim не нужны. Три фиксированные нагрузки + lifecycle decommit/recommit, обычно до минуты плюс обработка; ZIP создаётся автоматически. Пришлите ZIP даже при failed/unknown. Это синтетический own-child контроль, не доказательство пользы для Chrome.

Для полной партии запустите ElasticMem.exe и нажмите «Проверить всё (читает память)» вверху окна.
Один запуск: проверки, честные пропуски, остановка своего агента, ZIP логов автоматически.
Обычные вкладки Chrome/Edge или Steam должны быть открыты, чтобы нашлась пара рендереров.

Полное описание: **ПОЛНАЯ-ИНСТРУКЦИЯ.md**; оно также встроено в приложение — Лаборатория → Полная инструкция.
Для запуска без GUI: **CHECK-ALL.cmd** (закройте другое окно ElasticMem).
В ZIP логов по умолчанию нет дампов/контейнеров/трасс/screenshots; отправки нет. Просмотрите архив перед ручной отправкой.
Приложение не меняет MemoryCompression/PageCombining/pagefile и не реализует kernel VRAM pager/точную трассу Г0.

BUILD.json — коммит и хеши сборки. QA.json — реально выполненные/невыполненные проверки.
Windows runtime/GUI/GPU в Linux-среде сборки не исполнялись.

0.16: DMA-попытка без GPU_UPLOAD для RX570 и Г4-кодеки входят в обычную кнопку. Вмешательство Г0 в браузер требует отдельной галочки согласия; обычная калибровка trim затрагивает только собственный дочерний тестер.
