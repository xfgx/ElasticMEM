# Сжатие памяти активных приложений без VM и драйвера (active-trim)

Исследование и тест: постраничное вытеснение только холодных страниц чужого процесса, работающего в этот момент.
Сжимает их штатный Windows Memory Compression. Подробности и результаты см. в `FINDINGS.md`.

Тест на своём ПК: распакуйте набор и запустите `ТЕСТ-АКТИВНОЕ-СЖАТИЕ.cmd`, пока открыт браузер или мессенджер.
Права администратора не нужны. Тест длится 6 минут, отчёт сохраняется на рабочий стол.
