# Статус реализации

Г0: реализованы строгий контракт полного event-входа, ограниченная сценарная gap-score модель,
выборочный Linux page_idle коллектор, capability probe. Полный Windows collector не реализован;
поэтому вопрос «потолок на этой машине» пока **не измерен**.

Г3: подготовлен исходник D3D12 и Windows build/run/negative-check scripts. В Linux среде
нет Windows SDK/GPU; native файл **не скомпилирован и не запущен**, результат скорости отсутствует.
Нет драйвера pagefile, автоматической миграции VRAM при запуске игры, компрессии VRAM-страниц.

Г1/Г2: намеренно не внедрены до реальных данных Г0. Штатное combining не переключали.

Python correctness: unit + integration tests; фактический лог и число тестов сохраняются
отдельным selftest-run. Никакие synthetic результаты не включены в выводы о Windows.

Существующая C# база: попытка `dotnet build ElasticMem.sln --no-restore -c Release` заблокирована
NETSDK1064: в окружении отсутствует Microsoft.NET.ILLink.Tasks 8.0.31. Старый C# код не менялся.
Нет основания объявлять новую готовую сборку Windows-приложения.

Потерянные D/E имеют статус «заявлено ранее; сейчас не воспроизведено». Новая git история начинается
с сохранившейся базы, не восстановленной утраченной ветки. Дампы mem_python/sqlite/control — прежние
Linux снимки с неполной provenance; их hashes/архив не заменяют утраченные expdef-код и raw D/E.
