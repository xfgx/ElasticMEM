# elastic-arena — «песочница памяти» для Windows

Прозрачно-сжатая память в пространстве пользователя. Приложение (или движок) выделяет данные в арене;
горячие страницы лежат распакованными, холодные — сжатыми. Обращение к сжатой странице распаковывает
ровно 4 КиБ через механизм отказов страниц (VEH) — как `userfaultfd` в Linux. Windows при этом только
выдаёт и освобождает физические страницы, а решение «что держать в памяти» принимает арена.

- `src/codec.rs` — кодеки одной страницы: `Xpress` (ntdll, как у сжатия памяти Windows) и переносимый `Rle` для тестов.
- `src/core.rs` — переносимое ядро: состояние каждой страницы, компактное хранилище сжатых payload, выбор холодных. Тестируется на любой ОС.
- `src/arena.rs` — Windows: резерв адресов, VEH, фоновый компактор, освобождение физической памяти.
- `examples/arena_bench.rs` — стенд реального времени (60 Гц) с параллельным компактором и проверкой без потерь.

## Сборка и проверка

```
cargo test  --release --manifest-path rust/Cargo.toml -p elastic-arena        # ядро, любая ОС
cargo build --release --manifest-path rust/Cargo.toml -p elastic-arena --example arena-bench
rust/target/release/examples/arena-bench.exe 512 48 32 40                     # Windows: 512 МиБ, 40 с
```

Что это **не** делает: не перехватывает память чужого процесса. Прозрачно управляются только страницы,
выделенные через арену. Как подключить существующее приложение — см. `DESIGN.md` и его ограничения.
